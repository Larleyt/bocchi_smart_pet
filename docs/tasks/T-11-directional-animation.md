# T-11 — направленные анимации после одобрения поведения

Статус: deferred. Первым новым набором выбрана посадка на край [T-13](T-13-climb-and-perch.md). Направленные прыжки/диагонали остаются отдельным следующим набором; их кадры в T-13 не генерируются.

Запрошенная будущая семантика: движение вверх с углом больше45° к горизонту — прыжок; вниз — прыжок вниз; диагонали меньше45° в обе стороны — наклон корпуса как при подъёме по лестнице/в гору, без ступенек. Точный разбор границы45° и утверждение новых рисунков выполняются в этой задаче после снятия условия старта.
