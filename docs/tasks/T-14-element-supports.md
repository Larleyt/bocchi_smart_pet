# T-14 — опоры внутри приложений и сайтов

Deferred после первого набора [T-13](T-13-climb-and-perch.md), который использует края обычных окон. Добавить крупные панели/контейнеры с надёжно опубликованной рамкой и идентичностью, чтобы посадка работала внутри fullscreen приложения. Общие AXGroup/WebArea, кнопки и текст автоматически опорами не становятся. Для canvas без опубликованной структуры выделение объекта требует отдельного источника геометрии.

Сохранить front-only сценарий: подходит и садится перед элементом, без симуляции обратной стороны и глубины. Проверять свободную область тела/ног и локальный край; перемещение/исчезновение панели не должно оставлять привязку к чужому элементу. Не расширять разрешения и не добавлять постоянный полный захват. Реализация этого расширения не входит в T-13.
