# T-16 — рисованный спрайтовый бег

> Исторический этап. Текущая реализация, исправления и остаток — [T-17](T-17-run-front-seat.md). Описанные ниже старые кадры/ограничения не являются состоянием новой сборки.

Суставной результат T-15 отклонён; требуются рисованные спрайты. Конкретный критерий: уже в третьем спрайте впереди находится дальняя нога, ближняя отведена назад. Сжатие и смена масштаба относительно стоящей Боччи недопустимы.

Первый набор для визуальной проверки — четыре полных нарисованных кадра бега влево, 2×2 row-major: 1 контакт ближней ногой впереди; 2 полёт/перенос дальней ноги вперёд; 3 контакт дальней ногой впереди и ближняя позади; 4 обратный полёт/перенос ближней ноги вперёд, замыкание в1. Ближняя нога остаётся той же анатомической ногой, дальняя остаётся позади по глубине, даже когда её стопа вынесена вперёд по горизонтали. Идентичность проверять по корням бёдер и перекрытию контуров, не по разным оттенкам; одинаково розовые колготки допустимы. Руки противофазны. Одежда/лицо/пропорции прежние.

Использовать встроенный imagegen для полных рисованных спрайтов; не собирать итог из суставных частей и не подменять рисунок кодом. Диаграмма поз служит только входным reference. Сначала полный atlas и медленный GIF проверяются на порядок/анатомию, третью фазу и петлю. Непринятые рисунки не подключать в приложение. PNG/промпты/preview хранить внутри проекта, исходный PNG сохранять без изменений.

Граница этой итерации — исправленный рисованный вариант для визуальной приёмки. Код T-15 и другие анимации не переделывать до проверки новых рисунков; отсутствие интеграции указывать явно. Runtime-подключение следует за принятием арта.
