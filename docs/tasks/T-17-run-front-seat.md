# T-17 — исправить бег и посадку спереди

Продолжение T-13/T-14/T-16.

## Цель и дельта

Исходная сборка использовала отвергнутый суставной бег. Заменить его целыми
рисованными кадрами с реальным чередованием анатомических ног. При посадке
исключить перекидывание ноги через край: подход спереди, короткое опускание
в сидячую позу перед объектом. Расширить надёжный выбор опор и исправить отказы
поиска, сохраняя проверку всего тела/ног и защиты элементов управления.

## Приёмка

- В работающем SpriteView ближняя/дальняя нога меняются ведущей позицией при
  неизменных анатомических корнях и порядке перекрытия; цикл не сжимает фигуру.
  Требования: пропорции исходной стоящей chibi, маленький нос,
  компактные волосы/шаг; соседние естественные корни бёдер под центром юбки,
  без широкой перекрещённой полосы. Старый right-frame-03-source-v4 отвергнут.
  Последующее уточнение: СТРОГО боковой профиль90°, один видимый глаз,
  плечи/таз/обувь в профиль. Бег идёт в плоскости экрана, не к зрителю;
  красивый compact-набор3/4 тоже отклонён по ракурсу.
- Боччи подходит и садится в переднем слое без старых кадров перелезания.
- При неудаче одного кандидата проверяется другая доступная опора; перемещение,
  исчезновение и перекрытие опоры безопасно снимают/обновляют привязку.
- Внутренние опоры допустимы везде, где это уместно, кроме текста.
  Внутренние non-actionable контейнеры с читаемыми children не требуют имени:
  привязка использует идентичность настоящего AXUIElement, не координаты/индекс.
  Внутренняя опора требует видимой непрерывной кромки по всей ширине посадки;
  пустая невидимая AX-рамка опорой не считается.
  Изображения остаются unknown и допускаются только после прежней локальной
  visual/OCR проверки; текст и controls защищены. Неизвестный canvas не
  объявляется платформой по одному прямоугольнику.
- Компактный боковой бег сохраняет обычную защищаемую область120×156.
  Промежуточное расширение160pt для отвергнутого широкого рисунка отменено.
  Idle остаётся84×156 по центру; сидение128×156 с точкой опоры112pt.
- Сохраняются click/drag/hover, отмена устаревшего движения и прежние разрешения.
