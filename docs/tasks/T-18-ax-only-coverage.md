# T-18 — полнота размещения без захвата экрана

Без Screen Recording Боччи работает в браузере и некоторых приложениях, но не видит интерфейс ChatGPT. Начать после исправления бега/посадки [T-17](T-17-run-front-seat.md).

## Цель

По живому AX-дереву и коду выяснить причины недоступных областей в конкретных приложениях. Проверить различие ChatGPT и Codex (история — [T-8](T-8-fullscreen-accessibility.md)). Улучшить допустимые публичные способы чтения Accessibility, сохраняя защиту текста и controls. Не объявлять неизвестную область пустой только ради показа.

## Будущая проверка

AX-only вход `--diagnose-placement` → SystemInspector → PlacementSession → настоящий NSPanel. Сопоставить browser/native/ChatGPT либо Codex по фактическому bundle ID; не использовать host capture, не менять TCC и подпись. До реализации уточнить скоуп по фактическому диагнозу и пройти project spec/do + ponytail.

## Статус

Deferred до завершения T-17. В T-17 не исследовалась общая полнота AX-only; внутренние новые опоры требуют существующего visual opt-in.
