# T-29 — обезличить публичную историю и документы

## Цель и контракт

Удалить личные данные и секреты из текущего дерева и всей опубликованной истории.
Полностью удалить рабочий handoff, обезличить Git author/committer, локальные пути,
внутренние идентификаторы и выдержки из рабочих обсуждений. Удалить ссылки на
прежние коммиты, позволяющие открыть старые копии. Анимации и прототипы персонажа
сохранить без изменения байтов.

## Проверка

Реальный вход: публичные Git refs и blobs → изолированная фильтрация → push
с точной проверкой прежнего main → свежий анонимный clone и GitHub read-back.
Проверить всю достижимую историю, metadata, секреты, Markdown-ссылки и изображения.
Исходные личные данные и старые ссылки дают RED; очищенная история должна дать
ноль совпадений. Независимое ревью обязательно. Код приложения не меняется;
его сохранность подтверждается сравнением байтов в каждой паре коммитов.

## Координация публикации

Рабочие ветки после переписывания переносить поверх окончательного публичного
main только собственными изменениями. Старую историю не merge и не публиковать.
Архивы восстановления и отчёты с прежними идентификаторами остаются приватными
и не входят в Git.

## Blocked / deferred

GitHub продолжает отдавать недостижимые старые объекты и рабочий handoff по
прежним URL. Владелец поручил отправить единое обращение в GitHub Support после
полной перепроверки репозитория; серверная очистка остаётся внешней зависимостью.
Чужие клоны и внешние кэши не контролируются владельцем репозитория.
