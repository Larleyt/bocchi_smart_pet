# T-15 — пропорции и последовательный бег

Статус визуальной приёмки: суставной результат отклонён. Следующий вариант — полностью рисованные спрайты [T-16](T-16-painted-run.md), с дальней ногой впереди уже в кадре3. Числовые проверки ниже подтверждают работу реализации T-15, но не отменяют отказ от её художественного результата.

В замедленном диагональном preview видны деформация и несвязные ноги. По исходному коду crop160×208 ошибочно превращается в logical112×208 и draw84×156: ширина сжата на30%. В исходном running-right кадры0/2/3/5 повторяют одну позу, после4 сразу возвращается5; последовательной смены опоры и замыкания нет. Замедление проигрывателя эти дефекты не исправляет.

## Контракт до реализации

Обычный защищённый прямоугольник/NSPanel становится120×156: стоящая фигура по-прежнему84×156 по центру, беговой силуэт занимает до120×156 с единым масштабом поX/Y. Это сохраняет размер тела и головы и защищает всю ширину вместо расширения за пределы проверенного места. Perch128×156 остаётся прежним. PlacementSession использует существующий PetOverlay.size; drop центрируется, alpha hit-testing использует фактическую отрисовку. Внешние разрешения, подпись и AX/capture не меняются.

Новый цикл: восемь последовательных фаз для каждого направления — контакт, сжатие, отталкивание, полёт, контакт другой ногой и соответствующая вторая половина. Фиксированные пропорции, общий масштаб головы/тела относительно стоящего reference, ровная регистрация, замкнутые0→7→0, противоположные руки. Без подмены бега произвольными позами или отдельными несвязанными генерациями.

Первые полнофигурные imagegen-atlas с pose guide и точечной ревизией отклонены независимым art-review: четыре силуэта повторялись без смены анатомической опоры. На left-atlas ближняя нога остаётся впереди. Итоговый метод — нарисованные встроенным imagegen части персонажа + настоящая анимация по суставам в коде. Исходный PNG частей сохраняется без изменений, named crop-rects заданы в соседнем JSON и валидируются на границе. NativeRunRig один раз собирает кадры в памяти из частей, RunCycle задаёт постоянные длины бедра/голени, IK колена, разные траектории двух ног с половинным сдвигом и противофазные руки. Ближняя нога остаётся той же светлой частью, дальняя затемняется и рисуется за ней; порядок слоёв не переставляется для подмены ног. Left использует зеркальную геометрию и свой нарисованный torso, поэтому Rock! читается правильно. Каждый кадр имеет одинаковый canvas160×208, native draw120×156 масштабирует обе оси ровно в0.75.

Изменяемый runtime вход — обычный hover escape/PlacementSession.show→PetOverlay.move→настоящий NSPanel/SpriteView→отрисовка/alpha hit-testing. Узкий red→green воспроизводит исходную деформацию в реальной отрисовке; тесты сохраняют120 footprint/center/drop/perch, начало с phase0, порядок/замыкание и согласованное время. Фейки допускаются только для внешнего времени/мыши/файловых input fixtures. Арт проверяется отдельно по медленному циклу на месте и при диагональном движении рядом со стоящей моделью; зелёная смена кадров не доказывает механику ног. Отдельное ревью кода и визуальный просмотр фаз обязательны. Итоговый полный scripts/check.sh + подписанная сборка и preview из production renderer.

## Результат и доказательства

Исправлены оба дефекта: обычный safe footprint120×156 защищает всю ширину, standing остаётся84×156 по центру, бег рисуется единым масштабом0.75. `RunCycle` задаёт восемь фаз с постоянными длинами костей и половинным сдвигом дальней ноги. `NativeRunRig` сохраняет порядок слоёв и собирает оба направления из painted parts; суставы соединены без поперечных cut-caps. `SpriteView` начинает новое движение с фазы0, сохраняет порядок0...7, отменяет цикл при остановке/drag/climb и использует тот же рисунок для alpha hit-testing. Центрирование drop/perch и padding свободного места обновлены под полную ширину.

Финальные ресурсы: [PNG частей](../../Assets/bocchi-run-parts.png), [координаты и точки крепления](../../Assets/bocchi-run-parts.json). Рисунок создан встроенным imagegen, без CLI fallback; [точный набор промптов, включая финальный parts prompt](../../artifacts/20261016_153645_run_cycle/imagegen-prompts.txt). Отвергнутые полнофигурные атласы не используются. Исходный PNG частей не редактировался; alpha cleanup, крепление и движение выполняются native renderer при загрузке кадров.

Preview из production `SpriteView`/`PetOverlay`: [бег на месте ×4 медленнее рядом со standing](../../artifacts/20261016_153645_run_cycle/run-in-place-slow.gif), [обычная скорость](../../artifacts/20261016_153645_run_cycle/run-in-place-normal.gif), [диагональ ×4 медленнее](../../artifacts/20261016_153645_run_cycle/bocchi-diagonal-run-slow.gif), [все16 фаз](../../artifacts/20261016_153645_run_cycle/run-native-phases.png). Static [art-review](../../artifacts/20261016_153645_run_cycle/art-review.md): PASS, обе ноги/руки сохраняют идентичность, суставы соединены, все фазы внутри frame; видимая высота standing222px/run217px. Самое тесное место —3px снизу в фазах2/6 при масштабе contact sheet; произвольная будущая смена масштаба/траектории потребует повторного контроля краёв. Непрерывный просмотр GIF ещё не принят.

Полный `./scripts/check.sh`: **257 passed, 0 failed** —34 XCTest,209 runtime,8 signing,6 LaunchServices; release/plist/codesign успешны. [Финальный лог](../../artifacts/20261016_153645_run_cycle/final-check.log), [34-file SHA256 freeze](../../artifacts/20261016_153645_run_cycle/final-source-sha256.txt), повторная сверка всех34 записей успешна после gate. Четыре изолированные мутации успешно компилируются Swift6 и дают exit1: прежнее сжатие84×156; застывшая в фазе0 ближняя нога при остальных восьми разных кадрах; перестановка фаз через умножение индекса на3; прежнее глобальное время вместо начала движения. Настоящий NSPanel/SpriteView сравнивается с независимо отрисованной последовательностью и проверяет светлую/тёмную ногу по пикселям. Проверки malformed PNG/JSON не ловят собственное падение assertion: catch ограничен инициализацией ресурса, итоговый check выполняется снаружи.

Независимое [code-review](../../artifacts/20261016_153645_run_cycle/review.md): Ship, открытых Must/Should нет. ## Границы и откат

Направленные прыжки/наклон T-11 и опоры внутри сайтов T-14 не входят. Прямой маршрут между выбранными местами не заменяется pathfinding; проверка всего пути остаётся отдельным расширением. Более широкий безопасный footprint уменьшает число подходящих узких мест. Новые позы требуют отдельной визуальной оценки; приложение/кадры не объявлять принятыми автоматически.

Откат — revert отдельного коммита T-15 и пересборка с прежней .local-signing/. Приложение остаётся в dist/.
