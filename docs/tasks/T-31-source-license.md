# T-31 — Лицензия исходного кода

## Цель

По запросу оператора добавить явную OSS-лицензию перед заявкой Codex for Open Source.
Выбрана стандартная MIT для авторского кода, скриптов и проектной документации;
изображения, спрайты и другие медиа не получают лицензию на основании этого изменения.

## Скоуп файлов

- `LICENSE`: область действия и стандартный текст MIT.
- `README.md`: ссылка на лицензию и граница между кодом и медиа.
- Этот task-файл и `BACKLOG.md`.

## Приёмка

- Текст MIT совпадает с первоисточником Open Source Initiative, кроме года и
  публичного обозначения правообладателей `Bocchi Smart Pet contributors`.
- Область действия явно исключает медиа и не заявляет прав на стороннего персонажа,
  имена или товарные знаки.
- README ссылается на существующий `LICENSE`; исходники и assets не меняются.
- Изменение проверено независимо и сохранено отдельным коммитом.

## Проверка

Сравнение текста MIT с первоисточником, проверка области действия и локальных ссылок,
`git diff --check`, контроль состава diff. Runtime не меняется: native gate и
пересборка приложения не требуются. Работающий экземпляр из другого worktree не трогать.

## Анти-скоуп

Смена runtime, упаковки приложения и разрешений; публикация или push; реализация
Windows; выдача лицензии на сторонние медиа и персонажа.

## Blocked / deferred

Права и отдельная лицензия на медиа не подтверждены. Этот коммит их не устанавливает.
