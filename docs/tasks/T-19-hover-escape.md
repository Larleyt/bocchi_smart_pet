# T-19 — стабильное наведение и побег через пять секунд

Запрос 16.10.2026 после T-17: стоящая Боччи убегает только при наведении точно
по центру; в других точках головы/тела дёргается и мигает. Рабочая ветка —
`codex/run-and-front-seat`.

## Скоуп файлов

`Overlay.swift`, `InteractionCheck.swift`; при доказанной необходимости —
`PetInteraction.swift`, `App.swift`, `PlacementSession.swift` и их проверки.
Канон: этот task и `BACKLOG.md`.

## Приёмка и проверка

- Настоящий курсор/таймер → `SpriteView.tick` → hover event → session escape →
  выбор свободной позиции → видимое движение `PetOverlay`.
- На видимой голове/теле, в том числе вне центра, стоя и сидя: один побег после
  пяти секунд. До порога движения нет; прозрачное поле не вызывает побег.
- Повторная проверка безопасного места не меняет отрисованный кадр, не сбрасывает
  наведение и сохраняет работу click/drag, скрытия, движения и посадки.
- RED до исправления и GREEN после него; для critical path допустимы только
  внешние fake-границы времени, указателя и AX/capture.
- Независимое ревью, `scripts/check.sh`, native smoke подписанной сборки,
  сохранение разрешений, отдельный чистый commit.

## Диагноз и изменение

Подтверждённое мигание: `PlacementSession.refresh` повторно публиковал то же
место, а `PetOverlay.publish` каждый раз вызывал `sprite.stand()`. Направленный
взгляд на срок до следующего 50 ms тика заменялся исходным кадром. Исправление:
видимая неподвижная стоящая Боччи в той же позиции сохраняет текущий кадр.
Проверенная позиция после drag по-прежнему включает ввод. Движение, посадка,
скрытие и новая позиция проходят обычный путь публикации.

Гипотеза о перевёрнутой alpha-маске опровергнута независимой marker-калибровкой:
исходный `flipped: true` совпадает с отрисовкой и не изменён. На сетке из
52 559 точек нет пропущенных полностью непрозрачных пикселей головы/тела.

Сбой побега вне центра отдельно не воспроизведён. Сам сброс кадра не обнуляет hover
таймер: gaze восстанавливается до alpha-hit следующего тика. Поэтому исправление
мигания нельзя считать доказанным исправлением отдельного отказа побега.

## Blocked / deferred

Финальный native smoke после удаления диагностики заблокирован экраном блокировки:
`CGSSessionScreenIsLocked=1`, active displays пуст, online displays `[2,1]`.
Приложение поэтому получает `Display 2 is not available for capture` и повторяет
попытки. Это не положительный smoke финальной сборки; ранние 3 живых побега
относятся к сборке с временным trace. Проверить показ/hover после разблокировки.

Повторение конкретной неудачной точки оператора и его приёмка остаются открытыми.
Положительные проверки вне центра не доказывают отсутствие другого сценария
отказа. T-18 AX-only отложена по исходному порядку оператора.

Новый арт, изменение пятисекундного порога, TCC, перенос .app, host capture и
обход препятствий на всём маршруте в эту задачу не входят.
