# T-10 — спокойное размещение и взаимодействие с Боччи

## Запрос и границы до реализации

Требования: начальное место на спокойном боковом фоне, вдали от типичных верхних/нижних органов управления; при необходимости ближайший свободный участок; устранить оставшиеся исчезновения без изменений под питомцем; hover не скрывает, click вызывает взгляд вниз/удивление из существующих кадров, drag позволяет перенести, непрерывный hover без клика5s запускает плавный побег с существующим бегом. Новые изображения не генерировать. Направленные прыжки/наклоны вынесены в T-11 до ручной приёмки этого набора.

Слои: PlacementEngine + unit tests (начальный приоритет и ближайшая точка); PlacementSession (проверка кандидата, hover escape/manual drop, устаревшие результаты); App event/notification routing (без лишних hard hide); Overlay/Sprite/native mouse events (focus/click/drag/движение окна); runtime self-test; README/backlog. Существующие Screen Recording opt-in, локальный crop, лимит полного кадра, границы и ошибки сохраняются. Assets/подпись/разрешения не менять.

До правок требуется воспроизведение: Session/NSPanel при безопасном старом месте + stale external context не должны скрываться; реальная новая преграда по-прежнему блокирует размещение. Внешние fake границы только AX/pixels/время/мышь, production engine/session/native panel и таймер движения остаются настоящими. Unit red для начального поля и nearest; runtime red для отсутствия немедленного hover hide, click/drag/5s threshold и промежуточной позиции движения; отдельное независимое ревью.

Начальное боковое предпочтение — явная эвристика, а не обещание системного API определить фон. Позиция всегда проходит прежнюю AX/локальную проверку. Рабочая .app остаётся в dist, в Applications не перемещается. Сначала проверяется код/сборка, затем запускается обновлённая подписанная .app для ручной приёмки.

## Проверка и итог

Начальный поиск использует среднюю полосу: сверху72pt, снизу120pt, на низком экране каждое значение ограничено третью доступного вертикального хода. Внутри полосы предпочитаются боковые поля с отступом24pt и средняя высота; резервные зоны используются только если в средней нет свободной точки. Это начальное предпочтение не применяется к безопасному previous и nearestTo. После вынужденного ухода scoring выбирает ближайшую безопасную точку к предыдущему/ручному месту на существующей ограниченной сетке. Отвергнутый локальный crop добавляет реальные найденные obstacle bounds, а не запрещает всю площадь кандидата: небольшой текст не вынуждает отскок на ширину целого pet.

Session при устаревшем результате сохраняет последнее проверенное окно, но не публикует этот результат. Полная строгая проверка актуальности окон остаётся; смена generation блокирует stale completion. Изменение visibleFrame/Dock при том же физическом экране вызывает перепроверку, сохраняя подходящую точку. Переключение активного приложения — мягкая перепроверка, Space/физический экран/разрешения/pause — сброс. Подтверждённые новые преграды, действующая ошибка анализа и отсутствие уверенного места по-прежнему могут скрыть pet.

SpriteView использует alpha текущего кадра: за пределами фигуры окно пропускает клики, а активное нажатие удерживается до mouseUp даже при смене кадра. PetPanel не становится key/main. Click проигрывает существующий row7 со взглядом на Rock! и последние кадры waiting с раскрытыми ладонями. Drag проходит через настоящие mouseDown/Dragged/Up, переносит panel и проверяет точку после отпускания; до результата drop click-through. Hover без нажатия ждёт5s, затем запрашивает ближайшую безопасную точку. При переезде Timer60Hz меняет реальный frame и использует существующие кадры running-left/right; soft invalidate не прерывает бег, hard reset его отменяет. Assets не изменены, изображений не генерировали.

Проверяемые внешние fake границы: AX snapshot, pixels, время и mouse event. Engine/Session/native NSPanel/SpriteView/Vision и таймер движения остаются production. Runtime проверяет реальные промежуточные/final frame, soft/hard cancel, bitmap смены click-кадра, native drag/drop, захват зажатой мыши, прозрачный пиксель, отложенный hover и сброс после hide; Session дополнительно проверяет ручной crop, ближайший уход от маленькой преграды, сохранение при Dock/visibleFrame и stale context.

Полный `./scripts/check.sh` exit0: **22 XCTest + 123 runtime + 8 signing + 5 LaunchServices = 158 проверок, 0 failures** (artifacts/t10-final-check.log). Release/plist/codesign прошли. SHA8 изменённых критических source/test файлов зафиксированы в artifacts/t10-final-source-sha256.txt и совпадают после gate.

Отрицательные проверки: baseline до исправления с новым stale-context assertion даёт **56 passed / 1 failed** (artifacts/20261016_013600_t10_stale/baseline-red.log); отдельные engine red ловят прежний center/roomiest, отсутствие inset/reserved tier и перепутанные Quartz bands (artifacts/T10-placement-policy-*-red.log). Exact-freeze scratch mutations дают **10/1** на instant teleport, **17/1** на отключённый native drag и **0/1** на нулевую hover delay. Raw logs, patches и SHA — artifacts/20261016_014528_interaction_mutations/README.md. Рабочие source/dist/разрешения при этих mutations не менялись.

Нативная подписанная .app запущена из dist через LaunchServices: AX=true/screen=true/visualOptIn=true, shown(visual:true), первая точка — правое боковое поле с24pt отступом; повторные проверки delta=0 сохраняют позицию (artifacts/t10-final-live.log). В этом же процессе зарегистрированы настоящие dragBegan/dragChanged/dragEnded с ручной посадкой, затем hoverEscapeRequested и movementEnded с переездом на96pt. Эти события не инжектировались инструментом.

30s наблюдение только собственного CGWindow дало545 выборок,542visible,3absent,20 изменений фактического frame во время ручного drag (artifacts/t10-own-panel-watch.log). Краткое отсутствие совпало с подтверждённым локальным изменением: delta0.615 и obstacle=1, а не с rejected stale result. Нулевое число скрытий для этой смешанной проверки не заявляется. Ручная оценка настоящих кликов/drag/hover и внешнего вида остаётся отдельной от технических результатов.

Итог независимого ревью artifacts/t10-review.md после проверки freeze, raw red, полного gate и signed live: **Ship, открытых Must/Should нет**. Проверенные изменения готовы к ручной приёмке; новые направленные анимации до неё не запускаются.

## Настройка скорости после приёмки взаимодействий

Взаимодействия приняты, но побег оказался немного слишком быстрым. Длительность движения изменена с `min(1.2, max(0.22, distance / 650))` на `min(1.8, max(0.35, distance / 420))`: короткий переезд длится минимум0.35s, более длинные тоже примерно в1.5раза медленнее. Используются те же кадры бега; новых изображений нет.

Новый runtime-сценарий проверяет настоящий NSPanel при коротком96pt побеге: через250ms окно остаётся видимым и находится между началом и целью. Старый тайминг даёт ожидаемый **13 passed / 1 failed** (artifacts/t10-speed-baseline-red.log). Полный gate нового кода: **22 XCTest + 125 runtime + 8 signing + 5 LaunchServices = 160 проверок, 0 failures**, exit0 (artifacts/t10-speed-final-check.log). Актуальные SHA8 файлов сохранены в artifacts/t10-speed-source-sha256.txt. Независимое follow-up ревью в artifacts/t10-review.md: **Ship, открытых Must/Should нет**.

Подписанная .app с новым таймингом перезапущена через LaunchServices из dist, без стартового окна. Native trace подтверждает AX=true/screen=true/visualOptIn=true и shown(visual:true), затем повторные unchanged delta=0.000 (artifacts/t10-speed-live.log). Разрешения сохранены.
