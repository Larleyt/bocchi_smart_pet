# T-22 — спокойная анимация стоя

У основной стоящей модели слишком частые подёргивания и закрывания глаз.
Существующие шесть кадров проходят за 1.1 s, включая два моргания.

## Скоуп файлов

`Sources/BocchiSmartPet/Overlay.swift` (только длительности idle),
`InteractionCheck.swift` (проверка реальной отрисовки во времени), `BACKLOG.md`.
Изображения и T-21 остаются отдельной задачей; доступ к Flare здесь не нужен.

## Приёмка

Спокойные открытые кадры держатся около 3 s; закрытые глаза — только 0.12 s.
Порядок и сами рисунки сохранены, короткий жест головы читается без частого
повторения. Не замедлять общий 50 ms timer, взгляд/hover/клик, бег и посадку.

## Проверка

Внешний fake clock/pointer → настоящий SpriteView.tick → реальные пиксели
кадра. Сравнить с ожидаемыми исходными atlas-кадрами в паузах, коротком моргании,
жесте и после замыкания цикла. RED на прежних durations, GREEN на новых.
Полный scripts/check.sh, независимое ревью, подписанная сборка и native smoke
с сохранением bundle/signing/TCC/dist. Артефакты внутри проектного artifacts.

## Результат и проверка

Одна production-правка: длительности idle теперь `[3.0, 0.12, 0.4, 3.0, 0.12, 0.4]`,
цикл 7.04 s вместо 1.1 s. Сами кадры и остальные состояния сохранены.
Добавлены 13 проверок реального SpriteView; RED со старым темпом — 108 passed,
1 failed, GREEN — 322 passed, 0 failed. Полный `scripts/check.sh` — 370 проверок
без ошибок (34 XCTest + 322 runtime + 8 signing + 6 LaunchServices).
Независимое ревью: PASS, открытых замечаний нет.

Артефакты: `artifacts/20261017_161157_calm_idle/` — RED/GREEN, full gate, review,
подпись, hashes и native log. Подписанная сборка обновлена в прежнем `dist` и
запущена через LaunchServices. Для отката: revert этого T-22 commit и обычная
сборка с прежней локальной подписью.
