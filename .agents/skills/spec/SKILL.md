# Спецификация Bocchi Smart Pet

Прочитай применимые AGENTS.md, BACKLOG.md и затронутый код.
Используй существующую задачу в docs/tasks; новый T-id бери после проверки backlog.
Запрос только на спеку не разрешает реализацию. Ясный запрос исправить разрешает
подготовить недостающий контракт и продолжить через [do](../do/SKILL.md).

Запиши компактную дельту: цель, `## Скоуп файлов`, `## Приёмка`, проверки,
анти-скоуп и реальный Blocked / deferred. Для критического изменения фиксируй
настоящий вход → внутренние слои → наблюдаемый итог, внешние fake-границы,
команду и отрицательный контроль. Опирайся на фактические Swift/NSPanel пути.
Для анимаций различай техническую проверку кадров и визуальную приёмку оператором.
Артефакты помещай в artifacts/YYYYMMDD_HHMMSS_name по UTC+5.
Проверь локальные ссылки и соответствие статуса BACKLOG.md фактическому результату.
У этого проекта нет настроенной проекции Linear; внешняя синхронизация не требуется.
