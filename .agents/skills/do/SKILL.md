# Выполнение задачи Bocchi Smart Pet

Проверь ветку, status, diff и worktree; прочитай применимые AGENTS.md,
BACKLOG.md, task-файл и затронутый код.
Если контракт неполон, дополни через [spec](../spec/SKILL.md) и продолжай
уже разрешённую реализацию. Сохраняй чужие изменения.

Исправляй общую причину, прослеживая вызовы, загрузку/упаковку assets и native checks.
Для критического изменения докажи red → green на реальном runtime пути с явно
названными внешними fixtures. Проверка анимации включает отрендеренный SpriteView,
медленный цикл и анатомию; разные кадры/цвета сами по себе не доказывают качество.
Запусти целевые проверки и scripts/check.sh; независимому reviewer передай
diff, контракт, runtime evidence, отрицательный контроль и ограничения.

Сохраняй bundle ID, локальную подпись и существующие разрешения. Не меняй TCC,
не запрашивай host capture и не переноси .app в Applications. Перед заменой/запуском
проверь живой процесс; не завершай несвязанные экземпляры.
Документы и backlog обновляй по фактам, не называй visual acceptance завершённой
без ответа оператора. Проверенную работу коммить отдельно. Артефакты — внутри
проекта в artifacts/. Push/merge выполняй в пределах разрешённого запроса.
